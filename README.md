# ATOMA videos

Public hosting for finished ATOMA episodes (used by the posting scheduler). Source code lives in a private repo.

## Post kits
Every video has its files side by side: `<name>.mp4`, `<name>_no_music.mp4` (for adding a trending sound in the app),
`<name>_thumb.jpg` and `<name>_post.md` (title, caption, tags, posting time and where to post).

## Current videos (new format since Nov 4, 2026: fast style, Ultraviolet / Hologram for Chem)
- `4.1/` AP Chem 4.1 Part 1: Physical vs Chemical Change (27 s)

## Brand
`brand/` holds the logo kit in the new themes: Chem (Ultraviolet, magenta node) and Bio (Midnight Lab, lime node):
profile avatars (`*_avatar`), horizontal logos (`*_logo`), transparent marks (`*_mark_transparent`), as PNG and SVG.

## Archive
`archive/2026-11-04_old_format/` keeps the earlier videos (4.1 Parts 1–3 and Bio 3.1 Part 1 in the original format).
